WSR88 📝
​Une plateforme légère pour partager des notes, des textes et des photos avec des amis, directement connectée à Google Sheets.
​Fonctionnalités :
​Interface moderne : Supporte facilement le mode sombre et le mode clair.
​Partage de photos : Vous pouvez joindre n'importe quelle image pour qu'elle s'affiche pour tout le monde.
​Interaction et vote : Des boutons colorés pour interagir avec les publications.
​Stockage Cloud : Toutes vos publications et votre compte sont sauvegardés dans Google Sheets.
